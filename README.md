# 🎙️ Podcaster

> Uma plataforma web responsiva para criação de podcasts dinâmicos e totalmente gerados por Inteligência Artificial.

**⚠️ Status do Projeto: Em fase de Planejamento e Design** *Atualmente, o projeto encontra-se na etapa de prototipagem de interface (UI/UX) via Figma.*

---

## 📖 Sobre o Projeto

O **Podcaster** é uma aplicação web idealizada para revolucionar a criação de conteúdo em áudio. A plataforma permite que os usuários atuem como "diretores" de um podcast, configurando Agentes de IA que conversarão entre si de forma autônoma sobre um tema predefinido. 

O foco principal é a personalização total: o usuário não apenas escolhe o assunto, mas também molda a personalidade, o tom de voz e a dinâmica da conversa entre os participantes artificiais. Tudo isso em uma interface web moderna, responsiva (adaptável para desktop e mobile) e intuitiva.

---

## ✨ Funcionalidades Planejadas

* **Configuração de Agentes de IA:** Personalização profunda de pelo menos dois agentes simultâneos (ex: Host e Convidado).
    * **Voz:** Seleção de diferentes timbres e sotaques.
    * **Personalidade e Tom:** Ajustes via tags (ex: Sarcástico, Profissional, Entusiasta, Casual, Sincero).
* **Controle de Episódio:**
    * Definição livre do tema/tópico central (via prompt de texto).
    * Controle da duração média do episódio gerado.
* **Estúdio de Geração e Player Integrado:**
    * Interface de reprodução com visualizador de áudio dinâmico (waveform).
    * Indicadores visuais de qual agente está falando no momento.
    * Opções nativas para exportar e compartilhar o arquivo de áudio final.
* **Design Responsivo:** Layout adaptativo que funciona perfeitamente em navegadores desktop, tablets e smartphones.
